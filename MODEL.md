# Модель КПК: как довести до игры

Модель сгенерирована скриптами в Blender (`source/model/`): армейский КПК-«кирпич» в советском стиле. Оливковая краска со сколами до металла, резиновые отбойники и клавиатура, утопленный экран с интерфейсом «ВЕСТНИК ОС», антенна, разъём, ушко под ремень, батарейный отсек на винтах, наклейка ОТК, пломба, инвентарный номер, нацарапанная фамилия.

Превью: `source/model/preview/`.

## Что лежит в моде

| Файл | Что это |
|---|---|
| `KPK/data/kpk.p3d` | модель в редактируемом формате (MLOD) со всеми LOD: 1.000, 2.000, Geometry (масса 0.3 кг), Memory, View/Fire Geometry, Shadow |
| `KPK/data/kpk_co.png` | цвет |
| `KPK/data/kpk_nohq.png` | карта нормалей (царапины, сколы, рельеф) |
| `KPK/data/kpk_smdi.png` | блеск и отражение |
| `KPK/data/kpk.rvmat` | материал (шейдер Super) |
| `KPK/data/model.cfg` | секция `camo` для перекраски через конфиг |

## Шаг 1. Текстуры PNG → PAA

DayZ читает только `.paa`. Понадобятся три файла с **теми же именами**:

- `kpk_co.png` → `kpk_co.paa`
- `kpk_nohq.png` → `kpk_nohq.paa`
- `kpk_smdi.png` → `kpk_smdi.paa`

**Способ А, TexView 2:** DayZ Tools → TexView 2 → открыть PNG → File → Save As → выбрать `.paa` → сохранить рядом, в `KPK\data\`.

**Способ Б, ImageToPAA:** в папке DayZ Tools есть `Bin\ImageToPAA\ImageToPAA.exe`. Перетащите на него PNG-файл, рядом появится `.paa`.

Суффиксы `_co`, `_nohq`, `_smdi` в именах обязательны: по ним игра понимает, как сжимать текстуру.

## Шаг 2. Проверить модель в Object Builder

1. DayZ Tools → **Object Builder** → File → Open → `KPK\data\kpk.p3d`.
2. Справа в списке LOD должно быть: `1.000`, `2.000`, `Geometry`, `Memory`, `View Geometry`, `Fire Geometry`, `ShadowVolume 10000`.
3. В LOD `1.000` модель должна выглядеть как на превью (текстуры появятся, когда будут `.paa` и путь к P:, см. шаг 3).
4. **Если модель «вывернута»** (видно внутренние стороны, корпус выглядит прозрачным): в LOD `1.000` выделите всё (Ctrl+A) → меню **Faces → Reverse Face**. То же в LOD `2.000`.
5. В LOD `Geometry`: **Structure → Topology → Find Components** (должен найтись `Component01`). Масса: Structure → Mass, должно быть 0.3.
6. **File → Save.** Object Builder пересохранит файл в своём формате и заодно исправит мелочи, если они есть.

**Если Object Builder не открывает `kpk.p3d`:** создайте новую модель, **File → Import → FBX** → `source/model/kpk.fbx`, и пришлите мне скриншот, дальше проведу по шагам. В крайнем случае так и напишите, я поправлю генератор.

## Шаг 3. Упаковка с бинаризацией

Модели DayZ упаковываются **бинаризованными**. Для этого нужен диск **P:**:

1. DayZ Tools → **Workdrive** → Mount (появится диск `P:`). Если ещё не делали: там же **Extract Game Data**, это долго, но один раз.
2. Скопируйте папку `KPK` в `P:\KPK` (чтобы был `P:\KPK\config.cpp`, `P:\KPK\data\kpk.p3d`…).
3. Addon Builder:
   - **Addon source directory:** `P:\KPK`
   - **Addon prefix:** `KPK`
   - включите **Binarize**;
   - в **OPTIONS → Project folder** (если есть такое поле): `P:\`;
   - **Sign output PBO file**, как раньше.
4. **PACK.** В логе не должно быть ошибок про `kpk.p3d` и `.paa`.

## Шаг 4. Проверка в игре

1. Заспавните КПК: посмотрите, как он лежит на земле, в инвентаре и **в руках**.
2. Держание в руках взято от GPS. Если КПК в руке повёрнут не так или висит в стороне, пришлите скриншот. Я поверну или сдвину модель и пересоберу `.p3d`.
3. Если модель розовая или чёрная: нет `.paa` или не совпадает путь (`KPK\data\...`), смотрите лог Addon Builder и `script.log`.

## Как поменять модель самому

Всё генерируется скриптами, их можно править и перезапускать (Blender 4.x/5.x как Python-модуль, `pip install bpy numpy pillow`):

```
python decals.py <папка>                         # экран, надписи, наклейки → front.png, back.png, screen.png
python build.py -- <папка> 1024                  # модель + запекание текстур + FBX/OBJ/.blend
python lods.py -- <папка>/kpk.blend <папка>      # упрощённый LOD
python write_p3d.py <папка> <папка>/kpk.p3d      # сборка .p3d
```

Цвет краски: `PAINT = mat_paint("paint", (0.085, 0.098, 0.055, 1))` в `build.py`. Надписи и наклейки: в `decals.py`.
