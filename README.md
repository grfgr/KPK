# KPK: КПК сталкера для DayZ

Клиент-серверный мод в духе S.T.A.L.K.E.R. Добавляет **пять моделей КПК** и **разбитый КПК**. Устройство открывается клавишей **K** или действием «Включить КПК» с предметом в руках.

| Предмет (класс) | Что умеет |
|---|---|
| `KPK_Device` — КПК «Вестник» (кирпич) | профиль, карта, **контакты + рация**: быстрый звонок по контактам, голосовой звонок на несколько «Вестников» (группы нет) |
| `KPK_Stalker` — КПК-М1 | всё: профиль с репутацией, карта, группа, группировки, задания, заметки, **связь (общий чат)**, **контакты** |
| `KPK_Military` — ВПК-7М (ОКСОП) | всё, только для группировки ОКСОП |
| `KPK_Science` — ПИК №042 (НИИ) | всё, только для группировки НИИ |
| `KPK_Monolith` — ПИК №ОС-031 | всё, только для Монолита; чужого **взрывает** (50 урона, потеря сознания) |
| `KPK_Broken` — разбитый КПК | одноразовый: случайная координата из памяти, потом взрыв в руках |
| `KPK_Admin` — КПК-А «Куратор» | **только для администраторов**: игроки, админы, просмотр чужого КПК, управление группировками |

У каждой модели своё оформление интерфейса, приветствие и названия вкладок. Аккаунт один на игрока (позывной + пароль, привязка к Steam ID): с какого КПК ни зайди, данные общие.

Вкладки полной версии:

| Вкладка | Что внутри |
|---|---|
| **Регистрация / вход** | позывной + пароль, Steam ID подставляется автоматически. Пароль хранится только в виде хеша с солью |
| **Профиль** | досье (позывной, ранг, группировка, дата регистрации), статистика, состояние организма, репутация у группировок |
| **Карта** | карта мира, атмосферные метки (аномалия, артефакт, тайник, лагерь…), видны **только в КПК**. Метки можно править. Доступ: личная / группа / группировка |
| **Группа** | пати: приглашение по позывному, 3D-метки с позывным и дистанцией над союзниками |
| **Группировки** | состав, лидер, заместители, местоположение, описание; поля можно зашифровать от посторонних. Панель админа |
| **Задания** | любой участник группы и лидер/заместитель группировки выдают задания своим; API для других модов |
| **Заметки** | личные записи |
| **Связь** | общий чат сервера + личные сообщения |
| **Контакты** | список сталкеров: в сети / нет, группировка, «написать», «в группу» |

## Установка: шаг за шагом

### Что понадобится

- **DayZ Tools** (бесплатно в Steam, раздел «Инструменты»);
- архив мода: ZIP ветки с GitHub;
- доступ к папке сервера.

### 1. Подготовить DayZ Tools (один раз)

1. Запустите **DayZ Tools** → **Settings** → укажите путь **Workdrive** (пустая папка, например `D:\DayZWork`).
2. **Tools → Mount Drive**: появится диск **P:**. Внизу окна статус `Workdrive: Y`.
3. **Tools → Extract Game Data** (один раз, 10–30 минут): нужны ванильные файлы для Binarize.
4. Сделайте ключ подписи: **Tools → DS Utils → Create Key**, имя например `KPK`. Получится `KPK.biprivatekey` (храните у себя) и `KPK.bikey` (для сервера).

> После перезагрузки ПК диск P: пропадает. Снова: DayZ Tools → **Tools → Mount Drive**.

### 2. Положить мод на P:

1. Распакуйте ZIP. Скопируйте папку **`KPK`** (ту, где лежит `config.cpp`) в корень диска P:, чтобы получилось `P:\KPK\config.cpp`.
2. Переведите текстуры в формат игры: запустите **`tools/convert_textures.bat`** (переводит все PNG из `P:\KPK\data` в `.paa`). Нужно после каждого обновления моделей или текстур.

### 3. Собрать PBO

**DayZ Tools → Addon Builder:**

| Поле | Значение |
|---|---|
| Addon source directory | `P:\KPK` |
| Destination directory | например `D:\@KPK\Addons` |
| Binarize | **включено** (без него не работают анимации моделей) |
| Sign output PBO | включено, в **OPTIONS** указан `KPK.biprivatekey` |
| Add prefix | `KPK` |

В **OPTIONS → List of files to copy directly** должны быть `*.paa` и `*.ogg` (картинки рамок интерфейса `kpk_ui_*_ca.paa` и звуки `data/sounds/*.ogg` ни одна модель не использует, и без этих масок Binarize не кладёт их в PBO).

Нажмите **PACK**. Должны получиться `KPK.pbo` и `KPK.pbo.KPK.bisign`. Если ошибка `code=1` — закройте игру и сервер (PBO занят).

### 4. Установить на сервер

1. Папка мода: `<сервер>\@KPK\Addons\KPK.pbo` (+ `.bisign`).
2. Ключ `KPK.bikey` → `<сервер>\keys\`.
3. В строку запуска сервера: `-mod=@KPK` (вместе с другими модами через `;`). **Не** `-servermod`: мод нужен и игрокам.
4. Добавьте предметы в `types.xml` миссии (пример ниже) или в магазин трейдера.
5. Запустите сервер один раз. В папке профиля сервера (параметр `-profiles=`) появится `KPK\`:

| Файл | Что это |
|---|---|
| `settings.json` | все настройки (таблица ниже) |
| `admins.txt` | **админы**: один Steam64 ID в строке |
| `factions.json` | группировки (Одиночки, ОКСОП, НИИ, Монолит) и их задания |
| `parties.json` | группы (состав, метки, задания), переживают рестарт и обновление мода |
| `chat\` | архив сообщений (общий канал и личные), страницы по 500, до `ChatArchive` (10 000) |
| `password_salt.txt` | соль паролей. **Не трогайте и не удаляйте** |
| `accounts_index.json`, `accounts\<Steam64>.json` | аккаунты игроков |

6. Выключите сервер и впишите:
   - себя в **`admins.txt`** (17 цифр, начинаются с `7656`);
   - лидеров группировок в `settings.json` → `FactionRoster` (см. «КПК группировок» ниже), или потом прямо в игре.
7. Запустите сервер.

> Правьте файлы только при **выключенном** сервере. Ошибка в `settings.json` (лишняя/пропущенная запятая, Steam ID без кавычек) не сотрёт файл: сервер напишет в `script_*.log` строку `[KPK] !!! settings.json has an error`.

### 5. Установить игрокам

Тот же `@KPK` (папка с `Addons\KPK.pbo` и `.bisign`) у каждого игрока, запуск с `-mod=@KPK` (или через лаунчер / Steam Workshop, если вы его туда выложите).

**Версии должны совпадать:** у сервера и у игроков один и тот же `KPK.pbo`. Иначе при входе — «У сервера более поздняя версия» / «Клиент использует мод, которого нет на сервере».

### Проверка без мастерской Steam

Каждая загрузка в мастерскую проходит проверку Steam (от часа). Для тестов она не нужна:

1. Собирайте PBO прямо в папку тестового сервера, например `DayZServer\@KPK\Addons`.
2. Сами запускайте игру с тем же модом: `DayZ_BE.exe "-mod=<путь>\@CF;<путь>\DayZServer\@KPK" -connect=127.0.0.1 -port=2302` (лаунчер подставит старую версию из мастерской).
3. Друг подключается через **Radmin VPN** (бесплатно): вы создаёте сеть, он вступает, и в `-connect=` пишет ваш адрес из Radmin. Ему отправьте `KPK.pbo` и `.bisign` — пусть положит их в свою папку мода и запускает так же, с `-mod=` и `-connect=`. Вкладка LAN в лаунчере сеть Radmin не видит — только прямое подключение.
4. В брандмауэре Windows разрешите `DayZServer_x64.exe` для частных **и** общественных сетей (сеть Radmin Windows считает общественной).

В мастерскую загружайте **папку сборки** (`DayZServer\@KPK` или копию в `C:\Mods\@KPK`), а **не** `DayZ\!Workshop\@KPK` — там лежит то, что Steam скачал из мастерской, то есть старая версия.

### Обновление мода

1. Скачать новый ZIP → скопировать `KPK` в `P:\KPK` с заменой → `convert_textures.bat` (если менялись модели).
2. Собрать PBO (шаг 3) и заменить на сервере **и** у игроков. Настройки и аккаунты в профиле сервера сохраняются.

### Если что-то не работает

| Симптом | Что делать |
|---|---|
| Окно `Compile error` при запуске | скриншот ошибки разработчику |
| «У вас нет КПК» / КПК не открывается | нужна батарейка 9V в КПК (`RequireBattery`) |
| Пароль не подходит после правки настроек | в `accounts\<Steam64>.json` поставить `"PasswordHash": 0`, КПК попросит новый |
| Рации и звонки «Вестника» молчат | первая частота рации **80 МГц** в этой версии DayZ голос не передаёт: обычные рации ставьте на 2-ю частоту и выше. Звонки КПК её не используют сами (каналы 2–9) |
| «У сервера более поздняя версия» | у игрока другой `KPK.pbo`, чем на сервере (часто — старый из мастерской). Положите одинаковые файлы или запускайте с `-mod=` на свою папку |
| «Сервер не принимает настройки filePatching» | уберите `-filePatching` из строки запуска клиента или добавьте `allowFilePatching = 1;` в `serverDZ.cfg` |
| `serverDZ.cfg … Member already defined` | одна и та же строка (например `verifySignatures`) записана в файле дважды — оставьте одну |
| Addon Builder: PACK ничего не делает | закройте игру/сервер (PBO занят), проверьте ключ в **OPTIONS**, диск `P:` и папку назначения; при сборке в `Program Files` запускайте от администратора |
| Логи | клиент: `%LocalAppData%\DayZ\script_*.log`, `crash_*.log`; сервер: папка профиля. Ищите `KPK` и `SCRIPT (E)` |

### Пример для `types.xml`

Один блок на каждую модель; поменяйте `name`, количество и места появления (`usage`) под свой сервер:

```xml
<type name="KPK_Device">
    <nominal>10</nominal>
    <lifetime>14400</lifetime>
    <restock>1800</restock>
    <min>5</min>
    <quantmin>-1</quantmin>
    <quantmax>-1</quantmax>
    <cost>100</cost>
    <flags count_in_cargo="0" count_in_hoarder="0" count_in_map="1" count_in_player="0" crafted="0" deloot="0"/>
    <category name="tools"/>
    <usage name="Town"/>
    <usage name="Village"/>
</type>
```

Предлагаемые места: `KPK_Stalker` — Town/Village (редко), `KPK_Military` — Military, `KPK_Monolith` — нигде (выдача/квесты), `KPK_Science` — Medic/Industrial, `KPK_Broken` — Town/Village/Industrial (часто: это лут-загадка).

## Модели КПК

| Класс | Название в игре | Интерфейс | Функции |
|---|---|---|---|
| `KPK_Device` | КПК сталкера (КПК-7 «Вестник», кирпич) | зелёный люминофор | **базовые:** профиль (без репутации), карта с личными метками, контакты и рация (без группы) |
| `KPK_Stalker` | КПК-М1 сталкера | янтарь / сепия, «Добро пожаловать, сталкер» | все функции |
| `KPK_Military` | ВПК-7М (ОКСОП) | хаки / олива, закрытый канал, «Боец, доложите обстановку» | все функции |
| `KPK_Monolith` | ПИК №ОС-031 | бирюза, сильные помехи, минимум текста | все функции |
| `KPK_Science` | ПИК №042 (НИИ) | холодный бело-голубой, карточка сотрудника | все функции |
| `KPK_Broken` | Разбитый КПК | — | одноразовый, см. ниже |
| `KPK_Admin` | КПК-А «Куратор» | тёмно-синий, оранжевый акцент | все функции + терминал администратора, см. ниже |

«Все функции» — профиль с репутацией, карта (метки личные, группы и группировки), группа, группировки, задания, заметки, **общий чат и контакты**. Ограничения кирпича проверяются и на сервере, не только в интерфейсе. Аккаунт один на игрока: с какого КПК ни зайди, позывной, метки, заметки и статистика общие, меняется только доступный набор функций и оформление.

Все КПК, кроме «Куратора», работают от **батарейки 9V** (полные модели устроены как ванильный GPS, «Вестник» — как ванильная рация). Пока КПК открыт, батарейка разряжается (`BatteryDrainPercentPerMinute`), во время вызова по рации — как у обычной рации.

### Рация «Вестника» (только кирпич)

У кирпича нет группы: третья вкладка — **КОНТАКТЫ**: слева контакты аккаунта (добавляются на полном КПК, аккаунт общий), выбрать → **ВЫЗВАТЬ**; справа **РАЦИЯ**: можно и вписать позывной → **ВЫЗОВ**. У абонента должен быть свой «Вестник» с заряженной батарейкой: слева выезжает уведомление «входящий вызов», он открывает КПК → «Контакты» → **ОТВЕТИТЬ** (если руки пустые, «Вестник» сам ложится в руки). Неотвеченный вызов сбрасывается через `CallRingSec` секунд.

- **Говорить** — с «Вестником» **в руках**, в обычный голосовой чат. **Слушать** можно, где бы он ни был: в руках, на лямке, в рюкзаке.
- **Групповой звонок:** во время разговора кнопка «ВЫЗОВ» становится **«+ В ЗВОНОК»** — добавить ещё участника по позывному, до `CallMaxMembers` человек на одном канале. **ОТБОЙ** выводит из звонка; звонок кончается, когда в нём остаётся один.
- **Обрыв:** сразу — при смерти или выходе с сервера; если «Вестника» нет при себе, он сломан или села батарейка — через ~15 секунд (переложить из рук на лямку или в рюкзак можно спокойно). Причина пишется внизу и в лог сервера.
- **Каналы:** у каждого разговора свой канал рации, частоты **2–9** (первая, 80 МГц, голос не передаёт). Звонок обходит частоты, где уже кто-то передаёт (обычные рации, телефоны SFP). Когда свободных нет — «Все каналы заняты».
- **Громкость:** на время звонка голос из рации у участников вдвое громче, после звонка — как было.
- **Эфир не защищён:** обычная рация на частоте звонка слышит разговор (частота видна в уведомлении «Канал N»), стоящие рядом слышат голос из «Вестника».
- Вручную включить, выключить или перестроить кирпич как рацию нельзя: им управляют только вызовы.
- **Совместимость с SFP:** телефоны SFP тоже работают через рацию, но занимают каналы по номеру звонка без проверки (20 каналов при 9 частотах), поэтому их разговоры могут попадать на частоту звонка КПК. Чтобы реже пересекаться, уменьшите `CallChannels`.
- **Проверка в одиночку:** `TestCallEnabled: 1`, положите второй «Вестник» с батарейкой на землю в пределах 40 м, позвоните на позывной `ТЕСТ`: сервер включит лежащий «Вестник» как собеседника, и вы услышите себя из него.

### КПК группировок: чужим нельзя

| КПК | Чей | Если включит чужой |
|---|---|---|
| ВПК-7М | группировка `oksop` (ОКСОП) | «ДОСТУП ЗАПРЕЩЁН», КПК стирает память и ломается (ruined) |
| ПИК №042 | группировка `nii` (НИИ) | то же самое |
| ПИК №ОС-031 | группировка `monolith` (Монолит) | **взрыв в руках**, как у разбитого КПК: **50 урона, игрок теряет сознание**, КПК уничтожен |
| КПК-М1, кирпич | любой | — |

Проверка срабатывает при включении (клавиша K или действие в руках) — и у незарегистрированного, и у зарегистрированного игрока. Взять в руки и положить в рюкзак можно. Если в инвентаре несколько КПК, клавиша K включает сначала свой, чужой — только если других нет. КПК в руках включается всегда тот, что в руках.

**Кто в какой группировке** — три способа:

1. **В настройках сервера** (`settings.json`, ключ `FactionRoster`) — применяется при каждом запуске сервера:
   ```json
   "FactionRoster": [
       { "Faction": "oksop", "SteamId": "76561198000000001", "Role": "leader" },
       { "Faction": "oksop", "SteamId": "76561198000000002", "Role": "member" },
       { "Faction": "monolith", "SteamId": "76561198000000003", "Role": "leader" }
   ]
   ```
   `Role`: `leader`, `deputy` или `member`. Строки с `STEAM64_ID` — образец, сервер их пропускает.
2. **Лидер или заместитель в своём КПК**: вкладка «Группировки» → своя группировка → вписать позывной → **ПРИНЯТЬ В РЯДЫ**. Игрок зачисляется сразу и может пользоваться КПК группировки (если он не состоит в другой). Если нужно старое поведение с приглашением — `FactionDirectAdd: 0`.
3. **Админ в игре**: вкладка «Группировки» → выбрать группировку → вписать **позывной или Steam64 ID** в «Управление составом» → **ЗАЧИСЛИТЬ**; звания (лидер, зам) — выбрать бойца в «Составе» → **В ЛИДЕРЫ** / **В ЗАМЫ** (только админ). Или в `factions.json` при выключенном сервере. Группировки ОКСОП, НИИ и Монолит создаются сами при первом запуске новой версии, если их нет. Чей какой КПК — ключи `MilitaryFaction`, `ScienceFaction`, `MonolithFaction`, `StalkerFaction` в `settings.json` (id группировки, пусто — КПК для всех). Админы проходят проверку группировки (`AdminsBypassDeviceLock`, для проверки ловушки поставьте `0`), но панели администратора на обычных КПК нет. Всё админское — только в КПК-А «Куратор».

### Админский КПК «Куратор»

`KPK_Admin` выдаётся админу (спавн через админку). Включить его может только администратор (`admins.txt` / `Admins` в `settings.json`), у остальных — «ДОСТУП ТОЛЬКО ДЛЯ АДМИНИСТРАТОРОВ», без вреда для устройства. На всех остальных КПК админских возможностей больше нет.

- **Терминал** (первая вкладка): список всех зарегистрированных игроков (в сети — сверху, `[А]` — админ, группировка).
- **+ АДМИН / − АДМИН**: выдать или снять права по позывному или Steam64 ID. Список сохраняется в `admins.txt` и `settings.json`. Себя и последнего админа снять нельзя.
- **СМОТРЕТЬ КПК**: вход в КПК выбранного игрока (даже если он не в сети). Вкладки карта, группа, группировки, задания, заметки, чат, контакты показывают его данные; в заголовке «ПРОСМОТР КПК: …». Только чтение: любые изменения сервер отклоняет. **СВОЙ КПК** — вернуться; при закрытии КПК просмотр сбрасывается.
- **Группировки**: состав, назначение лидера, приём бойцов, шифрование полей, скрытие, цвет — панель администратора во вкладке «Группировки» (только в «Кураторе»).
- **Питание** «Куратору» не нужно: слота батарейки нет, разрядиться он не может.

### Уведомления и звуки

- Уведомления КПК — свои карточки **слева чуть ниже центра** со звуком сообщения (входящие сообщения, вызовы, приглашения, выход из сети). Карточка растёт под длину текста.
- Звуки интерфейса: щелчки кнопок, переключение модулей, модем при загрузке, тихий шум динамика, случайные писки и помехи (у Монолита — шёпот).
- Через `LogoutWithoutDeviceSec` секунд без КПК при себе игрок выходит из сети КПК и вводит пароль заново. Если у КПК села батарейка, он отключается и сеанс завершается сразу.

### Задания группы и группировки

**Админ** в КПК-А «Куратор» может выдать задание **ВСЕМ (АДМИН)**: оно появляется у каждого игрока как обычное задание, без пометки и без заказчика. Отмечает и удаляет такие задания тоже только админ в «Куратор»; хранятся в `factions.json`. В «Куратор» видны **все** задания всех групп и группировок (включая общие «ВСЕМ») — админ может отметить или удалить любое.

Во вкладке «Задания» у **любого участника группы**, у **лидера / заместителя группировки** есть кнопка **НОВОЕ ЗАДАНИЕ**: название, награда (необязательно), описание и кому — **группе**, **группировке** или **ВСЕМ**. Задание сразу появляется у всех участников (в списке с пометкой `[ГР]`, `[ГП]` или `[ВСЕМ]`), а у кого в сети и с КПК — уведомление. «ВСЕМ» — общее задание от группировки, его видят все сталкеры сервера; у каждой группировки одновременно не больше `PublicTasksPerFaction` (2) таких заданий. Задания группы может отмечать и удалять любой её участник, задания группировки — лидер / заместитель (общие «ВСЕМ» — только они). Кто вышел из группы или группировки, сразу перестаёт видеть её задания. Кнопки: **ВЫПОЛНЕНО** / **ПРОВАЛЕНО**, может **ВОЗОБНОВИТЬ** или **УДАЛИТЬ**. Задания группировки хранятся в `factions.json`, группы — в `parties.json`; кирпич задания не показывает.

### Связь и контакты

- **Связь** (у военных «Радиообмен»): общий канал для всех сталкеров на сервере. Перед позывным — сокращение группировки в скобках: `[НИИ]`, `[МОН]`, `[ОКСОП]`, у одиночек приписки нет. Своё сокращение группировке задаётся полем `Short` в `factions.json` (`"-"` — без приписки; пусто — по умолчанию, для остальных группировок берётся начало названия). Enter или «ПЕРЕДАТЬ» отправляет сообщение. Сервер хранит архив до `ChatArchive` (10 000) сообщений в папке `chat\` — переживает рестарт и обновление мода. При открытии КПК приходят последние `ChatHistory` (100), а стрелка `/\` наверху истории подгружает с сервера более старые по 50.
- **Контакты** (у военных «Позывные»): контакт нельзя «взять» без ведома человека — его можно только **отдать**. Наведитесь на сталкера → **«КПК: передать свой контакт»**: у него во вкладке «Группа» → «Входящие приглашения» появится «Контакт: ваш позывной», и только после **ПРИНЯТЬ** вы окажетесь в его контактах (чтобы он был у вас — он передаёт свой). Так же работает **«КПК: пригласить в группу»** — приглашение принимается во входящих. Обе подсказки появляются, только когда **оба** вошли в сеть КПК и держат в руках свой рабочий полный КПК (не «Вестник», своей группировки, с батарейкой) — сервер синхронизирует это всем клиентам. Во вкладке «Контакты» поле **ДАТЬ КОНТАКТ** делает то же самое по позывному (сталкер рядом, ближе `ContactMaxDistance`, оба с КПК в руках). Видно «в сети / нет сигнала», группировку и взаимность (`<>`). Кнопки «НАПИСАТЬ» (личное сообщение, видят только двое) и «В ГРУППУ» (приглашение в группу).
- Если КПК закрыт, но лежит в инвентаре с заряженной батарейкой, новое сообщение приходит уведомлением (`ChatNotifyClosed`).
- На кирпиче нет чата и группы; контакты есть только для звонков (список и удаление, добавляются на полном КПК).

### Разбитый КПК (`KPK_Broken`)

Вставьте батарейку 9V, возьмите в руки и выберите «Включить разбитый КПК»:
1. в уведомлении появится **случайный квадрат** из «памяти» устройства; если у игрока есть аккаунт КПК, точка добавится к его личным меткам («Запись разбитого КПК»);
2. устройство **взрывается в руках**: маленькая вспышка как от гранаты (уменьшенный эффект РГД-5), искры короткого замыкания, хлопок и треск разряда. Урон только тому, кто держит: **10–20 здоровья и 50 шока**. Устройство становится испорченным (ruined), батарейка разряжается в ноль.

### Модели и текстуры

Модели лежат в `KPK/data/` (`kpk*.p3d`), текстуры — PNG рядом с ними. DayZ читает только `.paa`: после каждого обновления текстур запустите `tools/convert_textures.bat` (переводит все PNG из `P:\KPK\data` в PAA через ImageToPAA из DayZ Tools). Исходники моделей (скрипты Blender, `.blend`, `.fbx`, превью) — в `source/`, в мод они не входят. Подробности о сборке модели — в [MODEL.md](MODEL.md).

## Настройки: `profiles/KPK/settings.json`

Если в файле ошибка (пропущена запятая или кавычка, Steam ID без кавычек), сервер **не трогает файл**, работает на настройках по умолчанию и пишет в `script_*.log` строку `[KPK] !!! settings.json has an error` с местом ошибки.

Админов проще вписать в `profiles/KPK/admins.txt` (создаётся сам): один Steam64 ID в строке, без кавычек и запятых.

## Группировки

### Права внутри группировки

| Роль | Что может |
|---|---|
| Лидер | принимать (приглашение по позывному), исключать, назначать заместителей и бойцов, передать лидерство |
| Заместитель | принимать, исключать бойцов |
| Боец | ставить метки группировки, покинуть группировку |

Игрок состоит максимум в одной группировке. Если у группировки нет лидера, первый вступивший становится лидером.

### Панель администратора (вкладка «Группировки»)

Админ выбирает группировку в списке.

**УПРАВЛЕНИЕ СОСТАВОМ** (над панелью):
- поле + **ЗАЧИСЛИТЬ**: позывной или Steam64 ID — игрок сразу попадает в группировку бойцом (без приглашения);
- боец, выбранный в списке «Состав»: **ИСКЛЮЧИТЬ**, **В БОЙЦЫ**, **В ЗАМЫ**, **В ЛИДЕРЫ**. **Звания лидера и заместителя назначает только админ** — на обычных КПК этих кнопок нет, лидер и зам только принимают в ряды и исключают.

**АДМИНИСТРАТОР · НАСТРОЙКИ ВЫБРАННОЙ ГРУППИРОВКИ** (внизу):
- переключатели показывают текущее состояние: **ОПИСАНИЕ / ЛИДЕР / СОСТАВ / МЕСТО: ШИФР или ОТКР** — что скрыто от посторонних (свои и админы видят всё); **В СПИСКЕ: ДА/НЕТ** — видна ли группировка посторонним; **МЕТКИ: ВКЛ/ВЫКЛ** — свои видят друг друга 3D-метками и на карте; **ЦВЕТ >** — следующий цвет палитры; **УДАЛИТЬ** (нажать дважды);
- поле **Текст** и кнопки **ТЕКСТ -> МЕСТО**, **ТЕКСТ -> ОПИСАНИЕ**, **НОВАЯ ГРУППИРОВКА** (название из поля);
- **Точка на карте**: **ГДЕ Я СТОЮ** ставит точку по позиции админа, **УБРАТЬ С КАРТЫ** убирает её.

То же самое можно править в `profiles/KPK/factions.json` **при выключенном сервере**. Поля: `EncryptDescription`, `EncryptLeader`, `EncryptMembers`, `EncryptLocation`, `Hidden`, `ShowMatesInWorld`, `Color` (0–9), `Location`, `HasLocationPos`/`LocX`/`LocZ`, `Members` (`SteamId` + `Role`: 1 боец, 2 заместитель, 3 лидер).

### Сброс пароля игроку

При выключенном сервере поставьте `"PasswordHash": 0` в `profiles/KPK/accounts/<Steam64>.json`. При следующем входе КПК попросит задать новый пароль.

## API для других модов (репутация и задания)

Серверная сторона, класс `KPK_Server` (модуль `4_World`):

```c
// репутация у группировки (id из factions.json), значение копится
KPK_Server.Get().AddReputation(steamId, "duty", 50);

// выдать задание: появится во вкладке «Задания», игрок получит уведомление
KPK_Server.Get().GiveTask(steamId, "q_flash", "Найти флешку", "Флешка в подвале НИИ...", "Сидорович", "5000 руб.");

// статус задания: 0 активно, 1 выполнено, 2 провалено
KPK_Server.Get().SetTaskStatus(steamId, "q_flash", 1);

// позывной и группировка игрока
string callsign = KPK_Server.Get().CallsignOf(steamId);
KPK_Faction faction = KPK_Server.Get().FactionOf(steamId);
```

Шкала репутации в КПК: ≤ −500 враг, ≤ −100 недружелюбно, до 100 нейтрально, до 500 дружелюбно, дальше «свой».

## Что считается в статистике

- убитые игроки (и самый дальний выстрел), заражённые, животные;
- смерти и самоубийства;
- время в игре, текущая и лучшая жизнь (обнуляется при смерти);
- пройденный путь (телепорты и респавн не считаются);
- ранг: от «Новичка» до «Легенды Зоны», зависит от убийств и времени в Зоне.
