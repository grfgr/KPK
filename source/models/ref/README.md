# Модели по концепт-листам

Четыре полные модели (ВПК-7М, Монолит, НИИ, КПК-М1) построены по концепт-листам 1536×1024:

1. `prep.py <лист.png> <mil|mono|nii|m1> out_<имя>` — вырезает виды (спереди, сзади, слева, справа, сверху, снизу) в атлас 2048×2048: цвет, карта нормалей (из яркости), smdi. Рамки видов — в `cfg.py`.
2. `blender python build_ref.py -- <имя> <абсолютный путь out_<имя>>` — корпус по пропорциям листа (скошенные/скруглённые углы, утопленный экран, выпуклые кнопки, ручки ВПК-7М, клипсы НИИ), UV проецируются на виды атласа. Пишет `mesh.json`, `mesh_lod1.json`, `kpk.blend`.
3. `../rebuild_p3d.sh <scratch>` — p3d с тремя позами (руки / лямка / инвентарь); текстуры копируются в `KPK/data` (`<модель>_co/_nohq/_smdi.png`, нормали с перевёрнутым зелёным каналом).

## v3/v4 — модели с нуля (текущие)

Форма и материалы собственные, лист — только образец пропорций и источник печатных элементов.

1. `tex_v3.py <лист.png> <имя> v3_<имя>` — бесшовные материалы (корпус, отделка, ткань: краска / металл / резина / плетение, цвета в `cfg_v3.py`) и фото-атлас (экран, задняя панель, верх кнопок, шильды, надписи). `tex_v3.py <лист> mil v3_shared shared` — общие металл и плетение.
2. `blender python build_v3.py -- <имя> <путь v3_<имя>>` — модель: корпус со скруглёнными кромками, ступенчатая ниша экрана, бамперы по контуру, кнопки, порты, клипсы, ручки, ремни, шильды; материалы по деталям.
3. `../rebuild_p3d.sh <scratch>` — p3d (несколько материалов на модель: `kpk_<имя>_body/_trim/_photo/_cloth`, общие `kpk_metal`, `kpk_weave`).

v4 (текущая): `gen_v4.py <лист> <имя> v3_<имя>` вместо фото-атласа рисует значки кнопок, светодиоды, шильды, надписи, полосы, знаки радиации и штрихкоды на фоне того же материала; с листа берётся только картинка экрана. Модель — `build_v4.py` (решётки рёбрами, пряжка, ремешок КПК-М1 — объёмные).
