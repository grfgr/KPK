# КПК-М1: вторая модель (по концепту, на будущее)

Альбомный КПК 178 × 98 × 28 мм. Тёмный потёртый металл с ржавчиной, рамка экрана на винтах,
три индикатора, кольцо со шнурком, кнопки (C, крестовина, трубка), ремень на петлях, шнур на углу,
сзади батарейный отсек с прорезями, табличка «КПК-М1 № 0473-11» и знак радиации.
Экран: «Карманный персональный компьютер. Модель 1».

**В мод пока не подключена.** Превью: `preview/`.

## Готовые игровые файлы: `game/`

| Файл | |
|---|---|
| `kpk_m1.p3d` | модель (LOD 1/2, Geometry 0.45 кг, Memory с `invView`, View/Fire Geometry, Shadow), ориентация как у текущего КПК (вариант D) |
| `kpk_m1_co/_nohq/_smdi.png` | текстуры 1024, перевести в `.paa` через TexView |
| `kpk_m1.rvmat` | материал |

Пути внутри модели уже указывают на `KPK\data\kpk_m1_*.paa` и `KPK\data\kpk_m1.rvmat`.

## Как подключить, когда понадобится

1. Скопировать содержимое `game/` в `KPK/data/`, перевести три PNG в `.paa`.
2. В `KPK/data/model.cfg` добавить `class kpk_m1: kpk {};` в `CfgModels`.
3. В `KPK/config.cpp` поменять у `KPK_Device` строку `model` на `"\KPK\data\kpk_m1.p3d"`
   (или завести отдельный класс-наследник, если нужны оба КПК).
4. Собрать с Binarize.

Держание в руках унаследовано от GPS (вертикальный предмет), а этот КПК альбомный. Возможно,
в руке его понадобится повернуть на 90°: это правится в `write_p3d_m1.py` (функция `to_p3d`).

## Пересборка

```
python decals_m1.py <папка>
python build_m1.py -- <папка> 1024
python ../model/lods.py -- <папка>/kpk.blend <папка>
python write_p3d_m1.py <папка> <папка>/kpk_m1.p3d
```
